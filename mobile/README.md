# Yekkola mobile

Flutter student app (Android first, iOS supported). Download-then-watch is the primary pattern.

- Conventions, layout and commands: [`CLAUDE.md`](CLAUDE.md)
- Architecture: [`docs/architecture.md` §6](../docs/architecture.md#6-mobile-architecture)
- Requirements: PRD-01 (sign-in, devices), PRD-06 (learning), PRD-07 (content protection, offline)

```sh
flutter pub get
flutter run --flavor staging
```
