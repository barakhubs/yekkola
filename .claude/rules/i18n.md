# Translation rules

- No hard-coded user-facing text anywhere. Every string has a key in **both** French (default) and English.
  - Web/admin: `packages/i18n` catalogues via next-intl.
  - API: `api/lang/fr` and `api/lang/en`; locale from `Accept-Language`.
  - Mobile: ARB files.
- Write the French first; it is the primary language. Keep keys namespaced by feature (`checkout.waiting.title`).
- Format money, dates, and phone numbers only through the shared formatters — never by string concatenation.
- SMS templates must fit 160 GSM-7 characters; check accented characters.
- Never mention a specific city (e.g. Kinshasa) as a default or example in copy.
